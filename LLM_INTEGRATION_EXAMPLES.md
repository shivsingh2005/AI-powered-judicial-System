# LLM Integration Examples

This document shows how each component now works with LLM-generated content.

## 1. Case Requests Generation

### Before (Mock Data)
```typescript
// data/mockData.ts
export const initialCaseRequests: CaseRequest[] = [
  {
    id: 'REQ001',
    userName: 'Rohan Sharma',
    caseSummary: 'Traffic violation...',
    // ... hardcoded static data
  }
];
```

### After (LLM-Generated)
```typescript
// components/CaseRequests.tsx
const fetchCaseRequests = async () => {
  const response = await fetch('http://localhost:8001/api/citizen/case-requests');
  const data = await response.json();
  setRequests(data); // Real LLM-generated cases
};
```

**Backend:**
```python
# app/services/ai_service.py
async def generate_case_requests(count: int = 3) -> Dict[str, Any]:
    system_prompt = "You are a legal case coordinator..."
    human_prompt = f"Generate {count} realistic case requests..."
    result = await invoke_json_llm(manager.primary, system_prompt, human_prompt)
    return result
```

**Result:** Each time you load the page, you get different realistic cases generated by Groq.

## Error Handling

### Missing API Key
```
ValueError: GROQ_API_KEY environment variable is required but not set or invalid.
```

### LLM Service Down
```
HTTPException(status_code=500, detail="API request failed: ...")
```

### Invalid Request
```
HTTPException(status_code=500, detail="No valid JSON object found in response.")
```
