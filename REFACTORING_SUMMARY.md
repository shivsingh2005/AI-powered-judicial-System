## Setup Instructions

### Prerequisites
```bash
- Node.js v16+
- Python 3.9+
- Groq API Key (free at https://console.groq.com/)
```

### Installation
```bash
# Frontend
npm install

# Backend
cd app
pip install -r requirements.txt
```

### Configuration
Create `.env.local`:
```env
GROQ_API_KEY=your_groq_api_key_here
```

### Running
```bash
# Terminal 1: Backend
python main.py
# Runs at http://localhost:8001/api

# Terminal 2: Frontend
npm run dev
# Runs at http://localhost:5173
```

## Breaking Changes ⚠️

1. **No Mock Fallback**
   - Missing API key = Hard error (not silent mock)
   - LLM service down = HTTP 500 error

2. **Different Response Format**
   - Some fields may vary based on LLM output
   - Responses more detailed and context-specific

3. **API Key Required**
   - Cannot run without `GROQ_API_KEY`
   - Must be valid Groq API key

## Support & Issues

### Common Issues

**"GROQ_API_KEY not set"**
- Create `.env.local` with your key
- Restart backend

**"API call failed"**
- Check internet connection
- Verify API key is valid
- Check Groq console for rate limits
- Look at backend logs

**"No valid JSON object found"**
- Try again (LLM responses can vary)
- Check backend console for details

**Frontend shows error**
- Ensure backend is running on `http://localhost:8001`
- Check browser network tab
- Look at browser console for details
