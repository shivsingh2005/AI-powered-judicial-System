# Data Directory

This directory previously contained mock data for testing and development.

## Current Status

**All mock data has been removed.** The application now uses LLM (Large Language Model) generated responses for all legal analysis and content:

### LLM-Generated Content
- **Case Requests**: Generated dynamically via `/api/citizen/case-requests` endpoint using LLM
- **Legal Analysis**: All dispute analysis comes from Groq LLM through `/api/citizen/analyze-dispute`
- **Similar Cases**: Generated via `/api/advocate/similar-cases` using LLM
- **Legal Arguments**: Generated via `/api/advocate/generate-arguments` using LLM
- **Research Results**: Generated via `/api/citizen/rag-search` using LLM
- **Chat Summaries**: Generated via `/api/chat/chat-summary` using LLM
- **Legal Drafts**: Generated via `/api/chat/legal-draft` using LLM
- **Bias Analysis**: Generated via `/api/chat/bias-monitor` using LLM

### API Endpoints

All endpoints require a valid `GROQ_API_KEY` environment variable.

#### Citizen Routes (`/api/citizen/`)
- `GET /case-requests` - Generate case requests for advocates
- `POST /analyze-dispute` - Analyze a legal dispute
- `POST /rag-search` - Perform legal research

#### Advocate Routes (`/api/advocate/`)
- `POST /similar-cases` - Find similar precedent cases
- `POST /generate-arguments` - Generate legal arguments
- `POST /ai-research` - Synthesize research into strategy

#### Chat Routes (`/api/chat/`)
- `POST /chat-summary` - Summarize legal discussions
- `POST /suggested-next-steps` - Suggest next steps in a case
- `POST /legal-draft` - Generate legal documents
- `POST /bias-monitor` - Analyze documents for bias

### Configuration

Ensure you have:
1. A `.env.local` or `.env` file with `GROQ_API_KEY` set to your Groq API key
2. Backend running at `http://localhost:8001/api`
3. Frontend configured to call backend endpoints

### No Mock Fallback

The application will **fail with an error** if:
- `GROQ_API_KEY` is not set
- The LLM service is unavailable

This ensures that all outputs are generated by the LLM and not mock data.
